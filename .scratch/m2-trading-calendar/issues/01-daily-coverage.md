# 01 · 從已稽核行情列出逐日完整性

**Parent:** [P2-02｜交易日完整性](../../../docs/DEVELOPMENT_BACKLOG.md#p2-02交易日完整性) · [規格與一次確認範圍](../spec.md)

**What to build:** 以合成市場日曆、兩股已稽核的行情 bundle 與指定期間跑完一份逐日報告，使用者可直接讀出休市、開市缺觀察與日曆不足。

**Blocked by:** 無（確認後可首先執行）

**Status:** ready-for-agent

**Review:** 2026-11-19 使用者已核准。合成資料開發。

## 完成條件

- [ ] 從私有 CLI 重現規格三個週一案例，另加入一個開市有行情的對照日。報告明列市場、股票、日期、截止、日曆版本、bundle 與理由，列數及各狀態計數可回算。
- [ ] 以已知的週末規則加例外、假日、原訂開市後臨時休市及跨年測試。跨年缺下一年日曆或市場不符時，列出受影響日期及未決理由。
- [ ] 休市卻有行情、兩個互斥公告缺取代關係時，保留衝突；公告在截止後才保存時，不影響舊截止的判斷。
- [ ] 舊版展示圖、該股不在選取範圍或行情範圍不足時，明列不可判；已存行情缺 close 保留該筆。覆蓋完整且開市卻缺列時，先列原因待查。
- [ ] 使用真實臨時 SQLite 產生合成研究版本並從 CLI 讀回。來源 hash 不符或超出預算時拒絕成功輸出，相同輸入重跑可重現。
