## 完成條件

- [x] 從私有 CLI 重現規格三個週一案例，另加入一個開市有行情的對照日。報告明列市場、股票、日期、截止、日曆版本、bundle 與理由，列數及各狀態計數可回算。
- [x] 以已知的週末規則加例外、假日、原訂開市後臨時休市及跨年測試。跨年缺下一年日曆或市場不符時，列出受影響日期及未決理由。
- [x] 休市卻有行情、兩個互斥公告缺取代關係時，保留衝突；公告在截止後才保存時，不影響舊截止的判斷。
- [x] 舊版展示圖、該股不在選取範圍或行情範圍不足時，明列不可判；已存行情缺 close 保留該筆。覆蓋完整且開市卻缺列時，先列原因待查。
- [x] 使用真實臨時 SQLite 產生合成研究版本並從 CLI 讀回。來源 hash 不符或超出預算時拒絕成功輸出，相同輸入重跑可重現。

## 驗證紀錄

2026-11-19 在 macOS arm64／Python 3.11.11 執行。測試由私有 CLI 讀取實際暫存 SQLite 產生的兩股合成 bundle，每個切片先取得失敗，再實作並重跑。程式候選 `28632cd`，執行方式及欄位見[使用手冊](../../../docs/CALENDAR_COVERAGE.md)。

- `uv run --locked python -m pytest -q local/tests/test_calendar_coverage.py` 通過 10 個測試及 14 個 subtests。含三種週一、跨年、臨時公告、矛盾證據、缺 close、範圍不足、完整性錯誤及回播。
- 基準 `798ae6d` 的沙箱首次驗收受 loopback 權限限制；授權重跑 `local.check` 通過 490 個測試及 246 個 subtests。候選 `28632cd` 同一完整檢查 exit 0，500 個測試及 260 個 subtests、SQLite 匯出與驗證通過。
- 私有證據位於 `local/private/m2-calendar/01/`，包括每個切片的 Red／Green 輸出、完整驗收 JSON。公開 repo 只保留合成測試與操作說明。01 範圍為離線工程行為；官方適用性、應到時點與序號見後續各票。
