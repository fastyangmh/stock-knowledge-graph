# 02 · 用個股及擷取證據解釋缺口

**Parent:** [P2-02｜交易日完整性](../../../docs/DEVELOPMENT_BACKLOG.md#p2-02交易日完整性) · [規格與一次確認範圍](../spec.md)

**What to build:** 從報告同一日的市場、個股與擷取證據，解釋停牌、無成交、抓取失敗、缺檔、晚到及原因未知。

**Blocked by:** [01 從已稽核行情列出逐日完整性](01-daily-coverage.md)

**Status:** resolved

**Review:** 2026-11-19 使用者已核准。合成資料開發。

## 完成條件

- [x] 同一開市日設兩股，一股官方停牌、另一股有成交。停牌日占交易日序號，停牌股無虛構報價，另一股仍有觀察。
- [x] 用有證據的無成交、僅缺收盤價、完全沒有個股列三個案例，核對各自原因、交易量／價值保留方式及分母。僅缺列時原因未知。
- [x] 以對應的失敗報告、預期檔案缺件清單分別重現抓取失敗與缺檔。同日兩種證據可並列；不相關市場、日期或來源的證據不可套用。
- [x] 在截止 A 的開市日缺觀察，截止 B 已保存該日行情。先驗證應到時點與首次可證實保存時間，再列晚到；證據不全時揭露限制。A 報告重播一致，未到期不標缺檔。
- [x] 透過同一私有 CLI 與合成檔案檢查可見原因、各自證據與報告分母。未知原因仍計入未解缺口。
