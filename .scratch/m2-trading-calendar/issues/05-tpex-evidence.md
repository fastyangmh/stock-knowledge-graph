# 05 · 核對 TPEx 官方日曆與例外公告

**Parent:** [P2-02｜交易日完整性](../../../docs/DEVELOPMENT_BACKLOG.md#p2-02交易日完整性) · [規格與一次確認範圍](../spec.md)

**What to build:** 對 TPEx 獨立建立適用上櫃市場的官方日曆樣本與證據清單，供報告查核一個有界區間。

**Blocked by:** 無（可與 TWSE 分別查證）

**Status:** resolved

**Review:** 2026-11-19 已完成 TPEx 11/14 至 11/17 的官方來源核對及私有 CLI 重播。[逐日預期、來源權利、封存邊界與重播證據](../../../docs/VERIFICATION-2026-11-19-TPEX-CALENDAR.md)。

## 完成條件

- [x] 定位 TPEx 適用上櫃股票的官方年度日曆與臨時休市公告來源。若官方明文採用另一日曆，保存適用依據、期間與 TPEx 例外規則；同日行情或兩市場日期相同不構成適用證據。
- [x] 留存來源定位、使用條件、取得／發布／首次保存時間、原始 bytes 的 SHA256、版本及涵蓋區間。擷取產物與原行情快照分處私有位置，日曆單獨識別。
- [x] 人工逐日查核至少一段含開市日與休市日的真實區間，區分交易與僅結算日，列出例外查核結果、未知日期以及變更的生效／取代關係。
- [x] 驗證介面是以固定 TPEx 樣本重播並對照人工預期。無法確認資料適用性或涵蓋範圍時，記錄來源、日期與具體缺口，保留未通過狀態。
