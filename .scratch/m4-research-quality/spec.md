# M4 私有提醒品質與事件描述統計

**Status:** needs-info

六條規則的分母、分組、截止重播、舊讀者與已保存的真實事件已通過[雙軸審查與重驗](../../docs/VERIFICATION-2026-11-19-M4-REVIEW.md)。P3-01 的長期與人工判讀案例仍需更多同來源、按時保存的歷史；P4A-01 的已核准工程與當前樣本交付已記在票 02。

## Problem Statement

研究者看到零次提醒或一個事件平均值時，需要知道有多少股票、期別與觀察原可參與計算，以及有多少因缺資料、來源變更或截止日期而排除。單日行情無法驗證有跨日後續值的樣本。

## Solution

以已稽核研究版本逐條檢視六項既有提醒，對每項提供分母、原始證據定位及人工案例。延伸現有事件描述統計，讓使用者辨識首次後續值、右設限、同股重疊及自選股票範圍。

## User Stories

1. 身為研究者，我要知道某規則有多少有效比較、觸發、未觸發、不可比和資料不足，才能讀懂零次提醒。
2. 身為核對者，我要從單一案例定位當時的設定、日期與來源版本，以辨認修訂、缺口及公司行為的影響。
3. 身為研究者，我要看到重複保存同一事件與同股另一事件的差別，以理解樣本間的相依。
4. 身為核對者，我要重播較早截止，看到當時的基準及後續值，以確認後來的修訂沒有改寫舊結論。
5. 身為研究者，我要知道哪些期間尚未走完、哪些來源不可比較，才能解讀各組有效數量。
6. 身為使用者，我要看到股票的選取方式和市場／期間覆蓋，以判斷結果能用在哪些樣本。

## Implementation Decisions

沿用六條規則、價量與月營收分開、閾值版本化、首次保存值，以及價量第 1／5／20 筆和營收第 1／3／6 個曆月的既定設定。採用已稽核版本及 P2-02 交易日旁證、P2-03 價格基準、P2-04 修訂／撤回資訊。各來源的定義與單位分組；任何新研究假說或人工標註準則另行確認。

## Testing Decisions

從正常的私有研究、事件分析及報告讀取入口驗證。使用跨截止且可辨識重複／重疊的合成研究版本驗證分母與相容性，再用真實歷史逐例核對。測試原展示裁剪、跨來源、不可比較、尚未到期、輸入範圍不足及零事件。實際來源僅存一日就記錄一日，逐規則列出可驗的案例。

## Out of Scope

策略 B、勝率、交易成本、顯著性結論、因果推論及新的研究定義。
