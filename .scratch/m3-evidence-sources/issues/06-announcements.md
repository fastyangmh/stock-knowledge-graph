# 06 · 官方重大訊息與多股引用

**Parent:** [P1-05](../../../docs/DEVELOPMENT_BACKLOG.md#p1-05重大訊息新聞與產業證據) · [規格](../spec.md)

**What to build:** 從允許保存的官方欄位建立穩定文件 ID、版本、股票對應與公告時間，透過現有文件介面重讀。

**Blocked by:** 無其他 M3 子票。真實交付依賴逐來源可用性、範圍與使用條件；來源撤回的正式串接依賴 P2-04。

**Status:** ready-for-agent

- [ ] 重複公告、跨來源轉載、文字注入、連結及撤回按版驗證。來源歸屬可追溯，文本使用受該來源許可範圍約束。
- [ ] 私有 CLI 的合成輸入走 SQLite、研究版本與 audit，驗證缺失、格式改變、同時衝突及故障保全。數值保持為數值，文字保留來源與股票映射。
- [ ] 真實採用的每一組市場／產業均保存官方原件、欄位定位、取得時間、版本與獨立核對證據；清楚列出尚未支援的組合。每份資料的使用範圍分開記錄。
- [ ] 儲存可重跑程序及去敏摘要，以原 backlog 條件評定整體狀態。只有工程通過時將真實證據另列待驗。

查證起點：[上櫃每日重大訊息](https://data.gov.tw/dataset/18418)
