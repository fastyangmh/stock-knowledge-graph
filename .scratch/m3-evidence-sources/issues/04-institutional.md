# 04 · 法人買賣及淨額

**Parent:** [P1-04](../../../docs/DEVELOPMENT_BACKLOG.md#p1-04籌碼資料) · [規格](../spec.md)

**What to build:** 按官方來源與法人分類讀入買、賣、淨額，透過現有研究流程保存籌碼數值。

**Blocked by:** 無其他 M3 子票。真實交付依賴逐來源可用性、範圍與使用條件；來源撤回的正式串接依賴 P2-04。

**Status:** ready-for-agent

- [ ] 以已核對案例確認股／張與正負號。核對合計與細項是否重疊；同日更新冪等並保留來源修訂。
- [ ] 私有 CLI 的合成輸入走 SQLite、研究版本與 audit，驗證缺失、格式改變、同時衝突及故障保全。數值保持為數值，文字保留來源與股票映射。
- [ ] 真實採用的每一組市場／產業均保存官方原件、欄位定位、取得時間、版本與獨立核對證據；清楚列出尚未支援的組合。每份資料的使用範圍分開記錄。
- [ ] 儲存可重跑程序及去敏摘要，以原 backlog 條件評定整體狀態。只有工程通過時將真實證據另列待驗。

TPEx 資料集將多組買、賣及買賣超分欄，原單位為股。上市來源的格式與權利需另外核對。[上櫃股票三大法人買賣明細](https://data.gov.tw/dataset/11856)

2026-11-19 對資料集 11856 的原始 CSV 全列重算。資料日期 1151118，共 899 列。七組法人欄位各有 899 筆符合「買進股數減賣出股數等於買賣超股數」。外陸資與自營商各自的買、賣、淨額合計均與所列細項相符。當日外資自營商三欄全為零，兩種三大法人加總方式都會相等，故當日資料無法判定該組是否應重複納入總計。保留來源已發布的總計及各自分類。這是來源內一致性檢查，獨立抽檢仍待驗。私有重跑與逐列差異在 `local/private/source-review-2026-11-19/institutional-check.py`、`institutional-check.json`。[TPEx 資料集與欄位](https://data.gov.tw/dataset/11856)
