# 01 · 季度綜合損益表

**Parent:** [P1-03](../../../docs/DEVELOPMENT_BACKLOG.md#p1-03季度財報) · [規格](../spec.md)

**What to build:** 用已核對的一般業來源完成 CSV 到未裁剪財務事實與 audit，再逐產業／市場擴展。

**Blocked by:** 無其他 M3 子票。真實交付依賴逐來源可用性、範圍與使用條件；來源撤回的正式串接依賴 P2-04。

**Status:** resolved

- [x] 負值、缺值、累計與單期、每股及金額單位分別測試。
- [x] 私有 CLI 的合成輸入走 SQLite、研究版本與 audit，驗證缺失、格式改變、同時衝突及故障保全。數值保持為數值，文字保留來源與股票映射。
- [x] 真實採用的每一組市場／產業均保存官方原件、欄位定位、取得時間、版本與獨立核對證據；清楚列出尚未支援的組合。每份資料的使用範圍分開記錄。
- [x] 儲存可重跑程序及去敏摘要，以原 backlog 條件評定整體狀態。只有工程通過時將真實證據另列待驗。

查證起點：[上市一般業](https://data.gov.tw/dataset/91998) · [上櫃一般業](https://data.gov.tw/dataset/94853)
