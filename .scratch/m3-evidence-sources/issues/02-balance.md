# 02 · 季度資產負債表

**Parent:** [P1-03](../../../docs/DEVELOPMENT_BACKLOG.md#p1-03季度財報) · [規格](../spec.md)

**What to build:** 以期末日的存量建立可抽檢的研究事實，按市場與一般業、金融及保險的來源欄位分別適配。

**Blocked by:** 無其他 M3 子票。真實交付依賴逐來源可用性、範圍與使用條件；來源撤回的正式串接依賴 P2-04。

**Status:** resolved（四份已核實來源與文件列明的樣本範圍）

- [x] 區分權益總額、歸屬母公司權益與每股淨值。相同股票、期末及來源修訂只保留一個當時可用版本。
- [x] 私有 CLI 的合成輸入走 SQLite、研究版本與 audit，驗證缺失、格式改變、同時衝突及故障保全。數值保持為數值，文字保留來源與股票映射。
- [x] 真實採用的每一組市場／產業均保存官方原件、欄位定位、取得時間、版本與獨立核對證據；清楚列出尚未支援的組合。每份資料的使用範圍分開記錄。
- [x] 儲存可重跑程序及去敏摘要，以原 backlog 條件評定整體狀態。只有工程通過時將真實證據另列待驗。

查證起點：[上市一般業](https://data.gov.tw/dataset/94831) · [上市金融業](https://data.gov.tw/dataset/94829)

## Comments

[資產負債表欄位、來源權利與私有驗收](../../../docs/QUARTERLY_BALANCE.md)。四個資料集各經 SQLite、研究及 audit，五家公司共 28 筆數值，17 筆完成同日同期獨立核對，另有 2 個原始空欄。上櫃金融與保險未啟用。合成回歸涵蓋零、負值與缺值、換表頭、流量核對誤用、同時衝突及晚到資料。
