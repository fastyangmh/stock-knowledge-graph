# M3 · 以來源為單位擴充私有研究證據

**Status:** ready-for-agent

## Problem Statement

目前真實來源驗證集中在公司、月營收與行情。研究者需要逐一看見季報、籌碼與公告的原始定位、定義與可得時間，才能判斷公司的數值或文字證據能支持什麼解讀。

## Solution

逐一打通來源族到既有私有研究、稽核與重播入口。每次只啟用已核對市場、資料集、商品、期間與允許用途的部分，每一種未支援的組合在適用範圍表列出。

## User Stories

1. 身為研究者，我要按報表及產業檢視季度指標，以核對當期與累計的定義。
2. 身為審閱者，我要查看負值、零及缺值對應的原始欄位及單位，以重做獨立抽檢。
3. 身為研究者，我要區分法人買賣與融資券餘額，以瞭解各項數值的來源。
4. 身為研究者，我要看到一次公告的公司關聯及更正，以重讀當時已知的資訊。
5. 身為維護者，我要讓可合法保存的文字、連結及衍生用途隨來源保存，以控制資料使用範圍。
6. 身為維護者，我要在來源結構變更時留下可定位的拒絕，並保有上一個研究版本。
7. 身為核對者，我要把已驗證之市場／產業與尚缺來源的組合分開，以安排剩餘抽樣。

## Implementation Decisions

沿用私有 raw、來源 registry／審核、正規化快照、ledger、研究版本與 audit。數值保留來源尺度、幣別、有效期與可得時間。使用來源可支持的穩定自然識別與版本，缺少必要定義時保存限制。來源查證與合成開發可平行，使用受限制服務及新增付費契約才另依授權辦理。

## Testing Decisions

各票以正常來源適配器 → 私有 normalized → 真實 SQLite research／audit 檢驗。合成 CSV／公告測格式漂移、缺值、原始檔篡改、重複、修訂、時間與來源衝突。真實採用時逐資料集保留使用條件、日期、欄位與單位依據，財務數值用獨立原始財報核對。已覆蓋的來源、產業、期間及仍受阻項以表列出。

## Out of Scope

正式金融資料發布、名單、第三方付費服務、交易與新增提醒規則。
