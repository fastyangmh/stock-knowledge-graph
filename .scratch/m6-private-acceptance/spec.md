# M6 真實私有研究總驗收

**Status:** needs-info

同候選 `02a8892` 已完成當前 macOS 的真實重建、兩市場更新與整組還原。行情獨立抽檢、目標主機復原及各原待辦的必要證據繼續追蹤。[同候選逐項驗收](../../docs/VERIFICATION-2026-11-19-M6.md)

## Problem Statement

個別工具通過測試後，仍需證明研究者能在同一候選版本、同一組設定與可定位的真實來源上完成研究，並能在故障後重建結果。

## Solution

從具體市場、股票與期間出發，在私有位置完成整套手動流程，以一份清單對回 M1～M5 的 backlog ID、來源範圍、實際命令及驗證結果。

## User Stories

1. 身為研究者，我要能從研究結論回查原始欄位、單位、可得時間和版本，以判斷它能回答哪個問題。
2. 身為核對者，我要知道同範圍的獨立抽檢比較了哪些欄位，以查核來源尺度。
3. 身為維運者，我要能在新的私有位置還原原始快照、SQLite、ledger、設定與研究版本，以重新執行 audit 和報告。
4. 身為接手者，我要區分合成回歸、macOS 實測、Linux／NAS 獨立復原及尚缺樣本，以了解目前能力。

## Implementation Decisions

以單一候選 commit 與可重建設定記錄版本。兩市場分開保存證據，逐資料集核對授權、證據獨立性及交易範圍。測試前後比對私有原件與公開示範資料的完整性。執行入口沿用 M1～M5 已通過的手動流程。

## Testing Decisions

從實際下載或已封存的真實原件到正規化、SQLite、模型、兩類提醒、研究版本、audit、前端與事件報告，逐階段記錄輸入輸出與 exit code。重播和獨立還原到全新的目的地。逐原 backlog 條件檢查分母、單位、時序、樣本、容量與授權；同候選完整測試與使用者路徑驗收分開列出。

## Out of Scope

公開、排程、交易、付費、對外聯絡、策略 B 與暫緩的名單。Linux／NAS 依實際環境取得後執行。
