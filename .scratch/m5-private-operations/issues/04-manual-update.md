# 04 · 分階段手動更新到已稽核的私有研究版本

**Parent:** [OPS-01](../../../docs/DEVELOPMENT_BACKLOG.md#ops-01完整手動更新流程) · [規格](../spec.md)

**What to build:** 維護者執行一次手動更新，逐市場看到來源日期、當期完整性、磁碟水位、各階段狀態與最後成功版本。

**Blocked by:** 已有來源與已核准的市場日曆介面；01 報告可獨立使用

**Status:** ready-for-agent

- [ ] 從已核准來源的取得、正規化、行情到 research／兩類提醒／audit 提供可選階段，允許用先前已驗 hash 的快照重跑。區分月報期別、取得日與交易日。
- [ ] 以臨時 SQLite 及本機檔案驗證休市、外部來源失敗、安全重試、audit 失敗及同輸入重跑，任何部分失敗保全舊成功 pointer。端到端成功路徑使用既有真實研究入口。
- [ ] 私有報告列成功、跳過、缺檔、不新鮮與失敗原因，預留退出碼供人工操作。以至少一次實際兩市場手動執行記錄資料來源與限制。
