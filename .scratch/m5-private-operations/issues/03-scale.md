# 03 · 量測精確搜尋的成本與容量上限

**Parent:** [P2-05](../../../docs/DEVELOPMENT_BACKLOG.md#p2-05容量量測與ann評估) · [規格](../spec.md)

**What to build:** 以固定 seed、模型 revision、硬體與輸入尺度重跑冷／熱快取，為索引選擇留下可重現依據。

**Blocked by:** 無

**Status:** ready-for-agent

- [ ] 保留編碼實際耗時、命中數、配對數與 CPU、峰值記憶體、輸出 JSON bytes 和瀏覽器載入時間。至少兩種代表性規模，說明固定環境與結果波動。
- [ ] 超預算須在昂貴工作前停止，舊研究可用。以小型可精確核對的 baseline 比較候選配對、分數及 recall；如沿用精確模式，明列可支援尺度與觸發重新評估條件。
- [ ] 若實測支持新索引，另拆相容、快取失效及增刪修訂票；重大依賴或硬體成本需決策，未量測不聲稱 ANN 必要或已有收益。
