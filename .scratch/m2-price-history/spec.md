# M2 歷史重建與價格可比性

**Parent:** [P2-03](../../docs/DEVELOPMENT_BACKLOG.md#p2-03公司行為與價格基準)、[P2-04](../../docs/DEVELOPMENT_BACKLOG.md#p2-04修訂與撤回)
**Status:** needs-info

價格比較、修訂與截止重播已通過[整合審查](../../docs/VERIFICATION-2026-11-19-M2-HISTORY-REVIEW.md)及[原生行情通知驗證](../../docs/VERIFICATION-2026-11-19-MARKET-NOTICE-REVIEW.md)。兩份正式更正可定位；實際撤回與其他受影響財務、籌碼原件尚缺。逐項恢復條件見[完成清單](../private-research-ready/completion.md)。

## Problem Statement

兩天都保存了行情，但遇到減資或拆股，價格差異可能來自股本變動。另一方面，一筆舊事實在新檔案缺席時，研究者不知道是遺漏還是來源正式撤回。兩者會影響日後能否重讀當時的資料。

## Solution

在私有研究中揭露比較期間的公司行為證據、未知範圍與價格基準。對來源明示的修訂和撤回保留歷史，使研究者可重建每個截止時點已知的事實。

## User Stories

1. 身為研究者，我要查到價格的原始基準與引用證據，以定位不能直接比較的區間。
2. 身為研究者，我要看到除權息、分割／併股、減資的已知事件及未知涵蓋，以判斷能否採信價格變化。
3. 身為維護者，我要按來源、股票及有效期驗證證據，以防另市場或另股票的事件被誤用。
4. 身為研究者，我要重播撤回前後兩個截止，以查明資料何時改變。
5. 身為核對者，我要區分來源缺列與明示撤回，以保全歷史資料。
6. 身為維護者，我要在同時更正彼此矛盾時得到診斷，以便核查來源。
7. 身為研究者，我要核對已封存的研究事實與首次後續值，以重讀較早版本。

## Implementation Decisions

未還原價格保留原值。公司行為比對以市場、股票、日期範圍、來源版本與時間為準；沒有可靠覆蓋須揭露。人為轉換公式、調整後報酬或新研究假說留待另外決策。現有研究 ledger 使用已保存快照及按截止 replay；新語意須識別來源修訂與明示目標，原始快照、舊分析版本及已完成 bundle 保留供重讀。

## Testing Decisions

用私有研究／比較報告與 research → audit 的入口驗證。以不可比的合成公司行為、來源未涵蓋的期間、已保存的真實官方證據及研究版本分別驗證。撤回測試使用真實臨時 SQLite，重播早／晚截止，驗證相同輸入、較晚修訂、程序失敗時可再跑，並核對舊 bundle 的 hash 與 audit。

## Out of Scope

策略 B、總報酬、交易、另購資料、推算未知調整因子。權利、官方資料覆蓋與工程測試各按實際證據記錄。
