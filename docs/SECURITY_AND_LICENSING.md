# 安全與資料授權｜Security & Licensing

> 本文件是專案風險控制與開發準則，不是法律意見。每個資料集均須核對當時適用的正式條款。

## 1. 公開與私有的界線

| 類型 | 預定位置 | 原則 |
| --- | --- | --- |
| HTML、CSS、JS、可公開的圖譜 JSON | GitHub 公開 Repository／Pages | 先驗證、確認來源與合法公開條件 |
| SQLite、原始官方下載快照、正規化私有資料 | `local/private/` 或不追蹤的本地路徑 | 預設不公開，不以 Git 提交 |
| Token、SSH key、憑證、模型存取權杖 | Linux/NAS 安全機制或環境變數 | 不寫進原始碼、README、log 或 `data/` |
| 模型權重及本地 cache | 私有設備 | 不提交公開 Repository，留意模型授權 |

**重要：** `.gitignore` 只是防止新檔被自動追蹤；如果敏感資料曾被 commit，還需要立即撤銷憑證並評估 Git 歷史曝光，不能只刪工作目錄的檔案。

## 2. 官方金融資料的授權

- **逐資料集確認**：TWSE、TPEx 與 MOPS 網站內容並非自動都屬同一種開放授權。已核對資料集與來源列於 [DATA_SOURCES](DATA_SOURCES.md)。
- **資料來源署名**：若適用政府資料開放授權，須檢查衍生輸出的顯名義務是否已真正顯示在網站上；manifest 有來源欄位不代表 UI 一定完成展示。
- **台灣50指數名單**：尚未確認允許本專案每天自動取得、保存歷史及在公開頁面呈現的權利。已準備 [授權詢問](TW50_LICENSE_INQUIRY.md)，未取得適用許可前不擅自爬取、發佈。
- **未涵蓋來源**：新聞全文、付費行情、重大訊息介面或其他業者資料不得用「在網頁能看到」推論可用於公開網站。
- **指數授權與標誌**：還須留意商標、指數名稱及第三方權利；若官方要求費用或簽約，須先讓使用者決策。

## 3. 資料採集安全

`local/source_registry.py` 限制已審核的資源 URL／主機／路徑；`local.collect_official` 會拒絕重新導向、超大回應、HTML／空 CSV、未核准格式，保存 SHA256 快照。來源請求有有限的重試規則，不應繞過 403、驗證碼或存取控制。

對於供應商的速率限制、更新頻率及授權異動，應更新 registry 與來源文件，不能因下載成功就自行擴大再利用範圍。

## 4. 發布與資料最小化

- 公開圖譜只包含需要的節點、邊與可追溯的必要欄位；不輸出私有 SQLite、原始文件或敏感欄位。
- `local.validate_release` 驗證端點、分數、檔案集合及路徑；`local.publish` 只允許 `data/` 下的預期 JSON 變更。
- **技術驗證不是授權審查**。發布前仍須確認來源的公開權利、署名、日期與內容。
- Pages 目前從 `main / root` 分支部署，**不能靠現有 GitHub Actions 測試阻止直接 push 後發布**。重大變更應採權限管理與人工審查流程。

## 5. 錯誤回報與稽核

請提交去識別化的錯誤訊息、測試結果與最小重現案例；勿公開 Token、內網路徑、受限制全文、未授權的成分股名單或完整私有資料快照。保留有關使用權利、版本與核准人的紀錄。

安全或授權疑問的處理：先停止有疑慮的公開發布 → 核對原始條款／官方回覆 → 記錄結論 → 必要時再修改程式與文檔。
