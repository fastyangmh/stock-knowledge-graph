## 已確認的方向與保存範圍

2026-11-16選定 **A：事件後變化統計**。價量提醒與月營收提醒分開研究；不假設買入、賣出、持有或成交價格，不計算策略報酬、勝率、alpha、因果效果或統計顯著性。

本工具從 `local.research` **已儲存且通過稽核**的研究版本取資料，無需TW50／009816名單，不下載金融資料、不執行SQL、不重算Embedding、不修改研究資料庫、公開 `data/`、排程或Git。它是描述已保存樣本的工具，**不是已完成的市場歷史事件研究或回測系統**。

## 事件與時間：先定義，後看結果

事件 = 同一股票、提醒規則、目標期別、提醒值正負方向、規則／來源定義之下，**第一次在所提供版本目錄保存的 triggered 結果**。

- 不是每次執行都算新事件。同期間同定義同方向的重跑或修訂，保留最早基準，另外計數重複出現次數。
- 同一規則在不同交易資料日期或不同營收月份觸發，會是不同事件；它們可能重疊、相關，不宣稱統計獨立。
- **不是首次突破門檻的「啟動事件」**：目錄可能從中途開始，先前狀態可能沒保存。不同定義（例如改門檻或來源）分開統計。
- 事件時間用研究版本的實際 `completed_at`，不是回填的資料期末日，也不是使用者指定的較早 `known_at`。今天重做去年資料，不假裝去年已產生提醒。
- 只納入在 `--as-of` 截止前已保存的研究版本。沒有提醒、沒有觸發事件或沒有後續資料，明確顯示，不據此聲稱沒有市場異常。

## 衡量方式（可調）

| 後續指標 | 預設觀察期間 | 計算方式 |
| --- | --- | --- |
| 收盤價變化 | 事件日之後第1／5／20筆**不同日期的已保存報價** | `100 × (後續收盤 / 事件基準收盤 − 1)` |
| 成交股數倍數 | 同上 | `後續成交股數 / 事件基準日成交股數`；不是除以前20筆平均 |
| 月營收金額變化 | 基準月之後1／3／6個**確切曆月** | `100 × (後續營收 / 事件基準營收 − 1)`；僅單位與幣別都明確且一致時 |
| 月營收年增率變化 | 同上 | 後續來源年增率 − 事件基準年增率，單位是**百分點** |

報價觀察不等於連續交易日：未有權威交易日曆驗證，不會把第5筆報價標成第5交易日。事件日同日的稍晚價格不納入後續期；缺失的價格欄位不跳過並改選下一筆。任一相鄰報價日期距離超過預設10個曆日，標記不可比較。

基準營收月份取事件版本裡最新可得的月份；某指標在該月缺失，不退回較舊月份。後續月份若已在事件實際保存日以前結束，標為不可比較，避免用滯後報告描述「事件後」變化。月份尚未結束為pending；已結束卻沒有保存該月數值，則是資料不足，不取最近月份代替。

**`source_reported`金額的倍率／幣別尚未確認，因此不計算金額變化。** 單位明確為percent的來源年增率仍可計算百分點變化。-30%變為-10%表示增加20個百分點，不能稱為已轉正成長。

## 修訂與來源

事件基準從事件當時版本凍結；後續值採該期在事件後**第一次保存的數值**，不使用較晚的最終更正版回頭改寫結果。報告標明 `followup_policy`；未來需要最終修訂口徑時，應新增不同版本的分析定義，不能默默更換。

不同來源、價格尺度／還原基準、市場、財報幣別／單位／範圍不混合。行情保留當時研究流程的原始CSV驗證旗標及SHA256；**這次分析不重新讀取CSV**，只稽核不可變 bundle 的已保存 bytes。這不代表資料來源真實性或公開權利已驗證。

## 分析版本與 cohort

| 分析版本 | `fact_scope` | 資料來源與限制 |
| --- | --- | --- |
| `event-study-2.0` | `unpruned_facts` | `Bundle.facts` 的[未裁剪研究事實](RESEARCH_FACTS.md)；保存範圍內的全部數值，不受展示上限影響，不代表完整市場歷史 |
| `event-study-1.0` | `display_graph_only` | 純舊 bundle 的展示圖數值；裁剪／未保存的資料不補值，保留原分析定義 |

新契約必須先由 audit 驗證，缺漏、未知版本或損壞不能退回圖譜。事件工具不開 SQL、不重新下載。新版證據使用 `fact_id`，與展示 node 是否存在無關；保留來源、可得／觀察／本地登錄時間及 unknown 狀態，不能用觀察時間代填未知登錄時間。比較鍵包含 `normalization_version` 與已提供的 `statement_scope`／`report_basis`，不同正規化版本或報表範圍標不可比較；原始逐筆數字與證據不充當定義版本。

純新或純舊目錄可自動選範圍；**混合目錄必須指定 `--cohort unpruned_facts` 或 `--cohort display_graph_only`**。一次報告只計算所選 cohort，不跨範圍合併分母。所有輸入仍先稽核，即使壞檔屬未選範圍也不能跳過。

JSON 與頁面列出版本、範圍、每個 cohort 的納入／未納入數量；`inputs` 列納入版本，`excluded_inputs` 列未納入版本及 `different_fact_scope`／`after_analysis_cutoff` 理由。無樣本保留空事件與分組，不生成零平均。

事件首次觸發仍以整個 supplied catalog 的截止前保存順序判定。如果同一事件首次保存在另一 cohort，後來在所選 cohort 重現，列入 `excluded_events`（`first_trigger_saved_in_other_cohort`），不以後來新版重建舊事件基準。相同完成時間跨範圍的事件無法決定先後，明確拒絕。後續值也只讀所選 cohort；新舊版本不互補缺漏。

## 統計與分母

每筆後續衡量有 `observed`、`pending`、`insufficient_data`、`not_comparable` 四種狀態。每組顯示事件總數、可計算數、各缺漏狀態數，以及可計算樣本的平均／中位數／最小／最大值。沒有樣本時統計是 `null`，不是0。

以**提醒類別、規則、定義版本、方向、來源／單位、後續指標與期間**分組；不合併兩類提醒成分數、不把正值稱為看多。不同期間可計算樣本數可能不同，不能忽略分母比較均值。樣本可能很少、重疊或存在存活者／選擇偏誤；不提供顯著性、預測能力或母體推論。

## 操作：只讀取已經存在的私有版本

先依[私有研究](PRIVATE_RESEARCH.md)累積啟用 `--alerts` 的事件版本，以及後續數值版本。後續版本可不啟用提醒，但須保存相同股票的可用數值。

以下為Linux Bash範例；分析截止時間不允許未來值：

```bash
uv run --locked python -m local.event_study \
  --root local/private/research-runs \
  --as-of "$(date -u +%Y-%m-%dT%H:%M:%SZ)" \
  --output local/private/event-studies/report-001.json \
  --serve --port 8767
```

同一台主機開啟 `http://127.0.0.1:8767/`。不需要網站登入、券商帳號或API Key。沒有同機使用者認證，不要將連接埠轉發到公開網路。只提供報告和必要頁面資產，不提供SQLite、原始檔案、目錄清單或其他研究版本；更新後須重啟。

`--output`選用，必須在來源目錄之外的私有位置。相同內容可重跑；不同報告不覆寫既存檔案，請改用新檔名。`--serve`選用，不啟用時只產生JSON與摘要。公開Pages上的 `event-study.html` 沒有私有報告，只會提示使用本機工具。

設定檔（`--config local/private/event-settings.json`）例：

```json
{"quote_horizons":[1,5,20],"revenue_horizons":[1,3,6],"max_quote_gap_days":10}
```

每種期間最多6個、報價期間1–252、營收期間1–24，須遞增且不重複。預設50版本／256 MiB檔案預算沿用catalog；可用 `--max-runs`／`--max-mib` 明確調整。另有2,000個截止前唯一事件識別（包含未選 cohort 的首次觸發辨識）、100,000筆所選範圍數值（新版含非事件指標／籌碼）、5,000,000事件／數值讀取組合與32 MiB報告上限。超額停止，不偷偷截掉事件；序列化大小上限不是Python峰值記憶體保證。

所有版本必須通過稽核、latest指標有效。毀損資料不得被默默排除以美化統計。這些檢查證明檔案內部一致性，不是數位簽章。

驗證紀錄：[原事件後統計](VERIFICATION-2026-11-16-EVENTS.md)、[新版完整事實與 cohort](VERIFICATION-2026-11-17-EVENT-FACTS.md)。

行情比較鍵另包含 `price_currency`、`volume_unit`、`turnover_unit`、`turnover_currency`、`trades_unit`、`trading_scope` 與 `normalization_version`，展示圖與完整事實讀者一致保留；任何定義變更均不可比較。原始 SHA256／逐筆審閱 evidence 不充當分組定義，避免同定義不同日期被拆成不同序列。這項相容性保護不替舊版未知尺度完成官方驗收，且不將 `source_unadjusted` 改稱還原價或總報酬。
