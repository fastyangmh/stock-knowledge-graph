## 建議閱讀順序

- **第一次使用網站**：使用者手冊 → 常見問題 → 術語表。
- **第一次接手開發**：System Design → Architecture → 開發者指南 → 資料模型 → 資料管線。
- **負責資料與發布**：資料來源 → 安全與資料授權 → 部署與維運 → 驗證紀錄。
- **規劃下一階段**：開發路線圖 → 台灣50授權詢問。

> 狀態備註：正式網站仍為虛構示範資料；真實台灣50名單的使用權、官方資料線上下載驗收、每日排程及正式資料公開發布均尚未完成。
