## 建議詢問事項

1. 是否有授權本地研究、自動化盤後取得、歷史回溯及每日更新的臺灣50成分股資料（含每次生效日期、剔除、納入及企業行為異動）？資料格式、取得方式、頻率與使用限制為何？
2. 研究者可否將原始成分股資料僅**保存在本地**，不對外散布？
3. 可否在**公開、免費的 GitHub Pages 研究網站**展示股票代碼、公司名稱、研究日期、是否為該日指數成分股及由此建立的知識圖譜？是否需要另外的展示、衍生作品、再發布授權？
4. 可否以歷史成分股資料執行統計分析與回測、保存歷史快照？是否允許在公開網站顯示僅包含摘要的歷史結果？
5. 是否需要同時取得 TWSE、FTSE Russell 或其他權利人的許可？相關授權窗口為何？
6. 授權是否區分個人研究、免費公開研究平台及未來商用？是否有費用、試用、最低訂購期限或免費研究方案？
7. 如獲准，應如何標示來源／版權、使用哪些名稱及商標聲明？是否有資料保留期限、下載速率及禁止事項？
8. 若成分股名單不適合本用途，是否有官方允許的替代資料或授權方式？
