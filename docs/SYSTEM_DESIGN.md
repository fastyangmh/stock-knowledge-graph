# System Design｜系統設計

[文件中心](README.md) · [Architecture](ARCHITECTURE.md) · [Roadmap](ROADMAP.md)

## 1. 願景與使用情境

Stock Knowledge Graph 是以股票為中心的**金融資料研究原型**，分階段完成：

1. **知識探索（目前核心）**：整理可追溯的公司、財務文件與語意關係，輸出可視化圖譜。
2. **異常訊號（規劃）**：比較財務、籌碼、新聞、事件變化，保留證據及訊號時間。
3. **量化研究（規劃）**：基於可得時間與歷史版本評估訊號，處理存活者偏誤及回測成本。

主要角色：一般網站使用者、金融研究人員、Local Pipeline 維護者、資料授權負責人。

**非目標（現階段）：** 自動交易、即時行情服務、未授權爬蟲、登入帳號系統、正式投資建議、可重現的完整歷史回測。

## 2. 已確認的設計決策

| 決策 | 原因／界線 |
| --- | --- |
| 台灣50為第一階段股票範圍 | 縮小資料量；官方名單與歷史授權仍待確認，禁止用 ETF 持股冒充 |
| Local Linux/NAS + SQLite | 保留資料控制權，避免公開主資料庫 |
| Python + uv + `uv.lock` | 讓環境與離線測試較可重現；遠端模型權重仍要另外固定 revision |
| Sentence Transformers + cosine + Top-K | 可分析文本相似，但**不等於因果、股價相關性或買賣訊號** |
| JSON + Cytoscape.js + GitHub Pages | 公開網站只負責展示，無常駐後端 |
| 每交易日盤後 **手動** 更新 | 未取得真實資料與發布驗收前，不啟用 cron/systemd 或無人值守 push |
| 部署採 `main / root` 分支 | 維持既有 Pages 設定；獨立測試不會自動阻擋直接 push |

## 4. 非功能需求與驗收條件

- **正確性：** 穩定股票／文件 ID；不重複節點；每條邊兩端均存在；分數有限且在 [-1,1]；當期資料必須有合適的來源與可得時間。
- **可追溯性：** 保留來源資料集、擷取時間、原始快照校驗碼、模型版本與必要關聯證據；若授權要求署名，展示頁也必須符合。
- **安全性：** 對外只公開允許的 `data/` JSON；本地私有資料／憑證不提交；禁用未審核的來源與下載繞路。
- **效能：** 無變動時避免模型重載和相似關聯重算；精確 Top-K 候選儲存控制在 O(NK)，但 CPU 運算仍可能是 O(N²×向量維度)。
- **可靠性：** 優先輸出私有預覽，驗證再發佈；失敗保留可用版本；人工檢查 Git 變更。
- **可再現性：** 使用 `uv.lock`、明確的資料快照與模型 revision；沒有模型 commit pin 就不聲稱完全可重現。
- **操作性：** 有單一離線驗收入口 `local.check`，不依賴 GitHub CI 作為主驗收方式。

## 5. 重要失敗模式及處理

| 風險 | 預期防護／剩餘風險 |
| --- | --- |
| 官方 CSV 變更欄位或下載返回 HTML | 驗證格式、欄位、空表與資料校驗碼；停止而非默默補值 |
| 台灣50成分股名單缺漏或資料過期 | 依日期載入、有重疊檢查；正式匯入需恰好 50 檔；尚待有權名單 |
| 財務資料未到齊、金額單位不明 | 覆蓋檢查、保留 `source_reported`；不擅自標為「元」 |
| 文件或向量未變，但股票對應變動 | 不重新算向量、須更新關聯圖譜 |
| 文件數暴增 | `--lookback-days`／`--max-pairs` 明確拒絕超額重算；ANN 未完成 |
| JSON 匯出失敗 | 暫存、結構驗證與有限度回復；不保證 NAS 斷電原子性 |
| 直接推送 `main` | **分支式 Pages 沒有強制等待驗證**；須依人工發布準則管理權限 |

## 6. 設計取捨

- **SQLite vs. 伺服器 DB：** MVP 適合 SQLite；若多人同時寫入或資料量顯著成長，再量測是否值得換 DB。
- **靜態 JSON vs. 後端 API：** GitHub Pages 維運成本低，但無法動態查詢完整歷史與私有資料。
- **精確 cosine vs. ANN：** 優先可解釋與精確結果，代價是資料多時須加入候選索引或分群搜尋。
- **展示裁剪 vs. 刪除歷史：** 展示只選取有限子圖，不能因此從 SQLite 刪除原始研究紀錄。
- **開放資料 vs. 指數資料：** 官方公開可看見 ≠ 有權自動下載及再散布；台灣50名單須獨立確認。
