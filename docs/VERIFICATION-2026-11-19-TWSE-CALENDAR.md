## 資料來源、權利與版本

兩份 CSV 均由臺灣證券交易所提供，政府資料開放平臺列提供機關為金融監督管理委員會證券期貨局，依政府資料開放授權條款第 1 版免費提供，利用時須履行顯名義務。下載沿用各資料集所列資源，以日期參數選取歷年資料，並以回應內的民國年／月確認版本。11761 每年更新且預設提供最新一版，11672 每日更新。[日曆資料集 11761](https://data.gov.tw/dataset/11761)、[每日成交資料集 11672](https://data.gov.tw/dataset/11672)、[授權條款](https://data.gov.tw/license)

一般制度網頁採既存私有快照核對，TWSE 網站第 6、8 條另規範下載方式與智慧財產權，開放資料集的授權適用於其授權標的。本輪僅交付私有重播樣本與本份來源摘要。[TWSE 網站使用條款](https://www.twse.com.tw/zh/terms/use.html)

## 私有離線重播

在保存證據的整合工作區執行下列命令。`expected.json` 保存上表的人工預期。`replay.py` 核對六份原件雜湊、開放資料資源、週期文字、年度列及成交日，從原件重算樣本，再比對三個條目的實際狀態。

```bash
.venv/bin/python local/private/m2-calendar/04/replay.py
```

2026-11-19 在 macOS／Python 3.11.11 重播 exit 0，六份原件、27 筆年度列、13 筆月成交列與四日預期均符合。複製到暫存目錄後修改成交檔一個位元組，重播因 hash 不符 exit 1。私有 `capture.py` 保存擷取命令，需要新版本時須指定全新目錄。首次 sandbox DNS 失敗另存 `probe/manifest.json`，取得網路權限後正常 HTTPS 擷取五份 HTTP 200。產品報告、正式行情單位與其他市場的驗收另計。
