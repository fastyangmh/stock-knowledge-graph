# 開發路線圖｜Roadmap

**文件狀態：2026-11-15。** 此頁區分「已實作／已離線測試」與「正式資料上線已驗證」。完成程式不代表真實來源、權利與網站都驗收通過。

## P0｜工程可靠性

**已實作／有離線測試：**
- uv lockfile、隔離 SQLite／語意假 encoder 測試與本地 `local.check`。
- 圖譜匯出前驗證、快照校驗、非法路徑與不相關檔案防護、人工發布 dry-run。
- 已記錄 69 項離線測試通過；較早版本另在 Linux/Python 3.11 實際驗證模型及向量快取。

**仍需：** 以最新版在指定的 Python 3.11 鎖定環境重驗、前端瀏覽器互動驗收、NAS 備份／斷電復原演練；不把舊版測試當成新版保證。

## P1｜合法官方資料與台灣50

**已實作：**
- 四筆已核對的政府資料集登錄表；先啟用上市公司基本資料及上市月營收。
- 官方 CSV 下載快照、SHA256、來源顯名資料、公司／月營收欄位映射。
- 當日及歷史成分股有效日期的 CSV 驗證、正式官方匯入恰好 50 檔覆蓋檢查。

**關鍵依賴／待辦：**
- [ ] 臺灣指數公司確認**台灣50成分股名單**可取得方式、歷史保存、自動更新、公開展示及衍生分析的權利；目前詢問信已準備、尚未寄送或收到授權。
- [ ] 實際下載並核對官方 CSV 全檔的欄位、可用性及更新時間。
- [ ] 確認月營收金額尺度、更新頻率、資料修訂及網站上來源署名。
- [ ] 逐資料集擴充價格、成交量、籌碼、季報、重大訊息與合法新聞資料（各有獨立授權與欄位適配）。
- [ ] 以**有權的真實當日資料**生成 50 檔私有圖譜，完成端到端驗收後才討論正式公開。

## P2｜圖譜成長、品質與效能

**已實作初版：**
- 以模型和文件 hash 的 Embedding 快取、無變動語意關聯重用。
- 精確 Top-K 的候選記憶體約 O(NK)，`--max-pairs` 與 `--lookback-days` 防止不受控運算。
- Graph Lifecycle：主股票 + 最多 100 個資訊節點 + 15 個相關股票；資訊節點語意邊上限 5；新聞 90 天。
- JSON 端點與 manifest 閉包驗證，移除未列入 manifest 的舊圖檔。

**仍需：**
- [ ] 真實資料規模與負載測試，評估 ANN／向量索引和增量圖譜策略。
- [ ] 版本化文件修訂、完整雙時間模型、研究可重建的歷史快照。
- [ ] 財報季數與籌碼事件的類型化展示保留規則。
- [ ] 前端來源署名、時間軸、載入更多、篩選 UX 及可用性測試。

## P3｜異常訊號發掘（規劃）

- 以財務、籌碼、新聞及產業事件建立**可解釋且具來源**的異常偵測。
- 確立訊號定義、時間戳、基準分布與誤報衡量；不直接以 cosine 當買賣建議。
- 需要合作人選定最優先的研究訊號及合理的資料取得範圍。

## P4｜量化研究與回測（規劃）

- 在合法、可重建的歷史資料上分析訊號後續表現。
- 處理成分股歷史變化、公告可得時間、公司行為、成本、存活者偏誤與樣本外驗證。
- 在資料權利與品質足夠之前，不提供報酬承諾或績效結論。

## 里程碑驗收規則

1. **私有資料可執行**：確實取得可用來源 → 對照授權 → 更新私有快照 → 完成 50 檔資料覆蓋與驗證。
2. **可研究**：日期與單位正確、資料與模型版本可追溯，語意結果有證據且無未來資訊洩漏。
3. **可公開**：已滿足相關權利、署名與內容審查，人工確認後才更新公開 `data/`。
4. **可自動排程**：多次真實人工執行穩定，包含失敗通知、重試、備份復原、資料行事曆與授權維護；**目前尚未達成**。
