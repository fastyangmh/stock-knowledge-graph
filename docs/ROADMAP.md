**現況：2026-11-16。** 以下區分已實作、離線驗證與正式資料上線；測試通過不等於官方來源、模型品質及網站都已驗收。

## P0｜工程可靠性

**已完成本輪工程驗證：** uv lockfile、本地 `local.check`、受控 JSON 匯出、來源／圖檔校驗、私有 loopback 預覽與人工發布防護。加入 SQLite 一致性備份、可驗證單檔備份及拒絕覆寫的還原工具。

本輪完整本地驗收為 **256 項 Python 測試、98 個子案例、27 項 JavaScript測試與11組瀏覽器情境**。瀏覽器使用記憶體fixture及本機Cytoscape，詳見驗證紀錄；不把它當成正式CDN／線上來源測試。

**仍需：** 最新版本在指定 Python 3.11 鎖定環境及真實模型重現、正式頁面實測、NAS斷電及異地備份還原演練。

## P1｜官方資料與研究股票池

**已實作：**
- 公司與月營收官方CSV快照、來源署名、日期／欄位轉換及SHA256。
- TWSE／TPEx盤後行情私有匯入與追加修訂；自選代碼不需要指數名單。
- `official_import --symbols` 與 `local.research` 將財務、行情、來源證據整合成私有圖譜。
- TW50＋009816聯集模式保留，名單各自日期及來源不混用。

**待辦（不以名單卡住其他工作）：**
- 正式官方CSV全檔下載、來源更新時程、數值尺度與修訂的現場核對。
- 完整季報、籌碼、重大訊息及合法新聞來源適配器。
- 名單取得與使用範圍**先暫緩**，不要求使用者現在寄信；真實雙來源資料公開前仍須確認。
- 真實資料與原始財報的抽檢、來源署名及網站內容驗收。

## P2｜歷史、品質與效能

**已實作：**
- 模型／內容hash向量快取、未變語意邊重用、精確Top-K有界候選、配對數安全上限。
- 追加式正規化觀察快照，保存來源觀察時間與本系統首次登錄時間；不回填成過去已知資料。
- 不可變私有研究版本、完整報告、跨版本向量快取複用、失敗保留舊版指標。
- 行情與財務數值使用獨立節點，不作為文字cosine；在100個資訊節點上限內為主要數值保留展示席位。
- 完整JSON驗證、舊圖清理、前端股票池／搜尋／來源詳情及手機介面。

**仍需：** ANN及真實大規模負載、完整雙時間財務模型、撤回／刪除事件、歷史版本查詢UI、類型化保留政策、儲存封存及配額。現有ledger只是本地登錄後的觀察紀錄，不是完整歷史市場重建。

## P3｜價量與月營收獨立研究提醒（初版已實作）

使用者已選定兩類都做、分開呈現。初版包含6條可調規則，明確列出比較期間、門檻、缺值狀態、來源證據及修訂截止時間；以 `local.research --alerts` 產生私有結果及圖譜下方的獨立面板。尚待真實資料校準、誤報評估、交易日完整性與公司行為處理，不宣稱投資有效性。

不把cosine或單次數值變化直接轉成買賣建議；未取得同意前不自行購買資料、提供績效宣稱或啟用交易。

## P4｜量化研究與回測（尚未實作）

以可重建的歷史資料進行事件後表現、基準比較及樣本外驗證；需處理成分股變化、公告可得時間、還原價格、公司行為、交易成本和存活者偏誤。研究假說、持有期間與評估指標須先確定。

## 上線與排程界線

本次維持手動私有流程，公開 `data/` 仍為示範，沒有cron/systemd或自動金融資料push。正式公開前需核對來源權利、金額尺度、日期、完整性與來源署名；自動排程前需多次真實資料成功執行、失敗通知、磁碟預算及復原演練。
