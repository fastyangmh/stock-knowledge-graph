## 操作方式

1. **股票池**：選全部、臺灣50（含重疊）、009816（含重疊）、兩者皆有、任一單獨來源或未標示。
2. **搜尋**：輸入股票代碼或名稱，與股票池條件一起過濾主股票清單。
3. **選擇股票**：載入該股票的圖譜。只下載所選圖，不為篩選下載全部資料。
4. **關聯類型**：依實際圖檔中的關係選擇資訊、語意、字元相似等；不在瀏覽器重算分數。
5. **節點／連線**：點選看詳情、模型識別、證據文件 ID、來源及可得時間。不存在的欄位不會被推測補上。
6. **重設視圖／重新載入**：前者適配圖譜，後者重新讀取索引及圖檔。手機寬度改變時自動調整圖譜。
7. **資料來源與使用條款**：展開看來源署名、資料集與條款連結。來源標記不是授權證書。

## 計數與日期怎麼看

股票池數量只代表**已匯出主圖**；同時屬兩者的股票在「全部」只計一次，在兩個來源各自的含重疊計數中都出現。未標示的舊圖不會被假設成臺灣50或009816。名單日期與 JSON 產生時間是不同資訊；多個日期一起展示時，會標示混合日期。

股票池／搜尋只過濾主股票清單，圖內仍可能有其他相關股票。相似度不是因果、股價相關係數或上漲機率。ETF 同日持股與指數有效期間不能互換；名單不會自動沿用至今天。

## 空結果與錯誤

找不到股票時調整搜尋或股票池。圖檔不存在、格式錯誤或索引與圖檔 SHA256 不一致時，畫面會清除舊圖並提示重新載入，不把舊圖當作新資料。來源未提供時顯示缺漏，不偽造來源。詳細排錯見 [TROUBLESHOOTING](TROUBLESHOOTING.md)。

## 本地私有預覽

已產生私有圖譜的維護者可執行：

```bash
uv run --locked python -m local.preview --data-dir local/private/combined-preview --port 8765
```

在同一台主機開啟 `http://127.0.0.1:8765/`，不修改公開 `data/`、不 commit 或 push。這個伺服器只提供圖譜及必要資產；不要使用通用根目錄 HTTP server 暴露私有 SQLite 或快照。限制與遠端 NAS 操作見 [前端與預覽](FRONTEND_AND_PREVIEW.md)。

## 尚未提供

目前沒有即時行情、自動交易、登入／訂閱、歷史時間軸、載入更多或量化回測。資料層存在的欄位不代表已完成金融品質驗證。進度與後續工作見 [ROADMAP](ROADMAP.md)。

## 私有行情與財務數值

新版私有研究版本可顯示「盤後行情」及「財務數值」關係。點選數值節點可看 OHLC、成交股數、期末日、單位、觀察／登錄時間與快照 SHA256。`source_reported` 表示尺度仍待確認；資料值不是相似度，也不是投資訊號。公開網站仍使用原示範資料，完整操作見 [私有研究手冊](PRIVATE_RESEARCH.md)。
