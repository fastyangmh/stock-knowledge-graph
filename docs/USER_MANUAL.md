# 使用者手冊｜User Manual

[文件中心](README.md) · [返回首頁](../README.md)

本手冊面向使用 **GitHub Pages 互動展示網站** 的一般使用者，不需要安裝 Python。

## 1. 開啟網站

前往 https://fastyangmh.github.io/stock-knowledge-graph/ 。

目前是**靜態展示原型，內容為虛構示範資料**，並非已驗證的即時台股資料；所有相似度與關係都不可直接當作買賣依據。

## 2. 操作介面

1. 在 **「選擇股票」** 下拉選單選擇要看的股票。列表由 `data/manifest.json` 提供。
2. 使用 **「關聯類型」** 過濾目前圖上的連線：**全部、語意相似、產業關聯、資訊關聯**。篩選依照邊的 `relation` 欄位，不會重新計算關係。
3. 用滑鼠或觸控點擊**節點或連線**，右側「節點資訊」面板會顯示其欄位內容，例如類型、來源、分數、方法或計算時間（實際以 JSON 含有的欄位為準）。
4. 點選 **「重設視圖」**，讓圖譜重新適配可視區域。
5. 圖譜下方顯示資料版本、產生時間及節點與連線數量。這是資料檔的版本資訊，**不是即時行情時間**。

`semantic_similarity` 代表模型文字向量相似度；`contains` 表示股票與資訊文件的連結；`industry` 是否存在須視當前資料內容而定。關係分數不等於投資機率、因果或股價相關係數。

## 3. 畫面示意資料流程

```text
選擇股票 → manifest 找到對應 JSON → 瀏覽器載入節點與連線
                             ↓
            選擇關聯類型／點選節點或邊／重設視圖
```

所有 AI 向量運算、SQLite 查詢和 JSON 生成都在本地處理；網站瀏覽器只讀取已發布的靜態 JSON。

## 4. 目前沒有的功能

- 尚無即時行情、自動買賣、登入、付費訂閱或投資建議功能。
- 目前沒有**文字輸入搜尋股票**；使用的是下拉選單。
- 目前沒有前端「載入更多」、歷史時間軸、策略回測或完整新聞全文查閱。
- 顯示節點數量與關聯數量會由本地匯出流程限制，但不代表 SQLite 只保存這些資料。
- 台灣50成分股的正式歷史名單尚未取得本專案所需的使用權利，不能將示範股票當作正式名單。

## 5. 本地預覽（選用）

有程式環境的使用者，可在 Repository 根目錄執行：

```bash
python -m http.server 8000
```

再開啟 http://localhost:8000 。請使用 HTTP server，不要直接雙擊 `index.html` 並以 `file://` 開啟，因為 JavaScript 會以 `fetch` 載入 JSON。

若無法載入，請先確認 `data/manifest.json` 與其列出的 `graph.json` 實際存在，並參考[常見問題與排錯](TROUBLESHOOTING.md)。

## 6. 使用資料的提醒

- 先檢查來源、發布／可得時間、模型及關聯證據，再解讀結果。
- 新增資料可能改變 Top-K 結果；「沒顯示」不表示「不存在」。
- 任何正式金融內容上線前，都須先確認資料正確性、來源署名及公開授權。
